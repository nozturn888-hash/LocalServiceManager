# 本机服务管家

[English](README.en.md) · [更新记录](RELEASE-NOTES.md) · [MIT 许可证](LICENSE)

本机服务管家（Local Service Manager）是一个 Windows 桌面与系统托盘工具，用来集中管理通过脚本启动的本机服务。它使用 C#、WinForms 和系统自带的 .NET Framework 程序集，不依赖 NuGet 包，也不安装额外的常驻后台组件。

公开版提供通用后台服务、ComfyUI 检查模板和客户端托管 stdio MCP 登记。业务服务、Python 环境、模型和 MCP 客户端需要另行安装；此项目不附带这些组件。

## 本机定制版与公开版的差异

**本机定制安装及其原有控制能力、服务条目继续保留。公开版 v0.1.0 是另外导出的通用便携发行，不是完整本机定制环境的迁移，也不提供原有五项本机服务的开箱配置。**

安装专用控制不仅依赖路径，还绑定外部运行时、控制器进程记录、API 或凭据链，因此公开核心没有直接移植这些能力：

| 能力 | 本机定制版 | 公开版 v0.1.0 |
| --- | --- | --- |
| Gateway 外部实例接管 | 保留原有专用控制 | GUI 不接管外部进程；另提供显式配置的自有脚本示例 |
| Local Codex Bridge 的 profile 与凭据链 | 保留本机专用适配 | 不分发该适配及本机 profile / 凭据链 |
| 工作台特有的队列与原子关闭接口 | 保留本机专用适配 | 不包含该接口集成 |
| ComfyUI Desktop 个人控制脚本 | 保留本机已有脚本 | 来源权利尚待核实，不分发；保留可编辑模板与队列守卫，使用者提供自己的脚本 |
| 初始服务配置 | 保留原有本机条目 | 空列表，两层自启关闭 |

[Hermes Gateway 脚本示例](examples/hermes-gateway/README.md)保留精确身份校验和官方进程记录的停止守卫，必须显式提供 `InstallRoot` 与 `Action`，没有实际安装路径默认值，也不会自动启用。它可以供使用者配置自己的控制脚本；公开 GUI 的通用服务仍不因此获得外部进程接管能力。

公开版会拒绝导入或执行旧的私人适配器配置；不要把本机配置直接当作公开版配置迁移。

## 运行发布包

需要 Windows x64 和 .NET Framework 4.x。界面使用 Windows 系统字体。

1. 从 [Releases](https://github.com/nozturn888-hash/LocalServiceManager/releases) 获取 `LocalServiceManager-v0.1.0-win-x64.zip` 和 `SHA256SUMS.txt`。
2. 解压到有写入权限的本地目录，保留完整目录结构。
3. 运行解压目录中的 `LocalServiceManager.exe`。

可用 PowerShell 检查下载包：

```powershell
Get-FileHash .\LocalServiceManager-v0.1.0-win-x64.zip -Algorithm SHA256
```

将结果与同一版本的 `SHA256SUMS.txt` 比较。程序数据保存在 EXE 同级目录，适合整目录备份：

```text
LocalServiceManager.exe
config/    服务配置与界面语言偏好
logs/      本工具捕获的输出与运行记录
icons/     复制保存的自定义图标
scripts/   自己配置的服务控制脚本
examples/  需显式配置的控制脚本示例，不自动启用
```

首次运行服务列表为空。工具随 Windows 登录启动、服务随工具启动这两层开关均默认关闭。

## 添加与使用服务

选择“新增”，先选管理方式，再填写配置；也可以把启动脚本拖入窗口。拖入只预填草稿，不保存或执行脚本。条目支持编辑、删除和拖动排序，托盘遵循相同顺序。

| 类型 | 管理范围 |
| --- | --- |
| 独立后台服务 | 配置自己的启动、停止和可选重启脚本；填写工作目录、参数、完整进程 EXE 路径、命令行唯一片段及健康检查。 |
| ComfyUI 模板 | 预填 8188 端口、HTTP 检查和队列保护；必须补充自己的启动/停止脚本与准确的进程身份。 |
| 客户端托管 stdio MCP | 记录所属客户端、命令、参数与说明；生命周期由客户端负责，本工具不独立启停、不读取协议流、不修改客户端配置。 |

核对脚本、参数与进程身份后，勾选执行许可并保存，才能操作独立服务。保存配置和启动服务是两个独立动作。

绿点表示运行，红点表示停止，黄点表示过渡；未知和错误会显示文字原因。状态结合进程身份、端口及可选 HTTP 检查判断，脚本退出不等于服务健康。已经运行的服务不会因点击“启动”被重新拉起。同一服务操作串行执行，重启等待停止完成。

公开版将外部启动的通用与 ComfyUI 实例视为只读。本工具管理的进程需要身份校验后才允许停止；它不会仅凭端口或 `python.exe` 名称结束其他进程。ComfyUI 有运行或排队任务时保护停止和重启，队列状态无法核实时也拒绝停止。请确保控制脚本本身同样遵守这些边界。

启动脚本通常在后台执行而不显示控制台窗口。需要交互输入或会自行弹窗的脚本必须先适配；隐藏控制台不能消除脚本本身的交互要求。路径可以包含空格和中文，脚本参数按原样传入，参数中的空格路径应使用双引号。

可以为条目设置网页 URL 或本机应用作为“打开入口”。主列表双击、Enter 或托盘“打开入口”只打开该入口，不启动或重启服务。

## 日志、图标与配置

内置日志视图支持捕获 stdout/stderr 或 tail 已有日志文件，提供搜索、复制和暂停滚动。缓存有上限，捕获日志会轮转；文件编码可选择 UTF-8、GB18030、UTF-16 或 Big5。服务原始日志属于用户内容，不随界面语言翻译。

图标可选内置图标，也可从图片、ICO、EXE 或 DLL 提取，支持多资源选择并复制保存。提取程序资源不会执行该程序，状态圆点与图标独立显示。

导入只添加配置，不执行导入项；导入后的自启和执行许可关闭。导出会移除脚本/应用参数、身份命令片段、进程记录、登记备注和 URL 查询信息，并使用内置图标。服务名称、路径等字段仍会保留，分享前请检查这些自由文本。导出用于交换安全配置，不替代完整的本地备份。

## 语言、自启与退出

在“工具设置 → 界面语言”选择简体中文或英语。选择立即保存并切换程序自身的标题、主界面、编辑窗口、设置、托盘、提示与模板文字；保留排序、选择和输入草稿。用户自定义的服务名称、说明、命令、路径、URL 和日志不会自动翻译。系统原生文件选择框按钮及系统组件生成的文字遵循 Windows 或组件语言。

两个自启开关独立：

- 工具自启：“工具设置”中的“Windows 登录时启动本工具并收进托盘”。
- 服务自启：该服务“配置 → 启动与停止”中的“随工具启动此服务”。服务运行或操作期间配置只读，需停止后才能修改并保存；stdio 登记由客户端负责，不提供独立自启。

关闭主窗口会收进托盘，隐藏时降低轮询频率。托盘可查看各服务状态并执行允许的启动、停止和重启操作。

- “退出工具（服务继续运行）”只退出管理器，保留服务。
- “停止本工具管理的服务后退出”先尝试停止本工具管理且可安全控制的服务。身份或任务保护阻止停止时，工具会提示并保留当前状态；不会强制结束外部进程。

## 从源码构建

使用 Windows 自带的 .NET Framework C# 编译器和 Windows PowerShell，不需要还原 NuGet 包：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

便携程序位于 `dist/LocalServiceManager-v0.1.0-win-x64/`，EXE 在该目录根部。

编译隔离测试：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Tests
.\tests\Tests.exe
```

`-Tests` 只编译测试程序；显式运行 `Tests.exe` 才执行隔离生命周期、GUI 和托盘检查。测试使用隔离 fixture，不操作用户的真实业务服务。

## 第一版边界

v0.1.0 不提供故障自动重启。公开版未分发针对开发机器的专用适配器，其他服务可以通过自己的通用脚本配置，stdio 服务仍交由客户端管理。跨机器的脚本、路径、端口和服务身份需要自行核对。

验证范围见 [更新记录](RELEASE-NOTES.md)。真实业务服务启停与 Windows 自启持久设置的实际写入未作为发布验收；不承诺固定的常驻 CPU 或内存数字。
